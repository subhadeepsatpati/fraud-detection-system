# Fraud Detection System Using Machine Learning

## Project Overview

This project is a Machine Learning based Fraud Detection System developed using Python and Scikit-learn. The system detects fraudulent credit card transactions from a highly imbalanced dataset.

Fraud detection is very important for banks and online payment systems to reduce financial losses and improve transaction security.

---

## Objective

- Detect fraudulent transactions using Machine Learning
- Handle imbalanced data
- Train classification models
- Evaluate fraud detection performance
- Understand business risks related to fraud

---

## Dataset

Credit Card Fraud Detection Dataset from Kaggle.

Dataset Link:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
